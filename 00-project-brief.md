# 00 — Project Brief

## One-line description

ChoreMatrix turns a household's people, workload and constraints into a workable chore/work allocation.

## The problem

Most households do not struggle because they lack a list of chores. They struggle because the household has to repeatedly answer:

- Who should do this?
- How much work is each person carrying?
- What can each person realistically handle?
- What happens when somebody is unavailable?
- How do recurring responsibilities rotate?
- How do we avoid silently dumping the invisible planning work on one person?

Existing chore products often focus on tracking completion, reminders, points or household dashboards. ChoreMatrix starts one level earlier: **calculate the plan**.

## The product loop

1. Describe the household.
2. Describe the work.
3. Describe important constraints.
4. Generate a plan.
5. Review imbalance/conflicts.
6. Rebalance or regenerate.
7. Save/share the result when it is useful.

## Core value proposition

> ChoreMatrix calculates a household workload plan instead of making the household manually divide the work.

## Why web first

A browser is a strong fit because the user needs to compare multiple people, tasks, capacity, workload and constraints at the same time. A desktop/tablet layout can expose the optimization result in a way that is difficult to achieve on a small screen.

## Initial market thesis

The market has real demand and multiple competitors. The product therefore should not compete on "having chores" or "having a fairness score." The initial wedge is the **optimization event** and its breadth across different household configurations.

## Current success definition

A new user should be able to describe a household and reach a credible first plan in less than three minutes without creating an account.

## Hard product constraints

- No AI API dependency.
- No paid external API dependency.
- No native mobile requirement.
- No document/records workflow.
- No need for the user to manually maintain a complicated task system before seeing value.
