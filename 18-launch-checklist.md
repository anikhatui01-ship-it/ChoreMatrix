# 18 — Launch Checklist

## Product

- [ ] first-time user can reach a result without signup
- [ ] household presets work
- [ ] task presets work
- [ ] custom tasks work
- [ ] capacity is respected
- [ ] hard constraints are respected
- [ ] overload is reported
- [ ] rebalance works
- [ ] explanations are understandable

## Frontend

- [ ] responsive desktop UI
- [ ] responsive mobile browser UI
- [ ] keyboard navigation
- [ ] loading states
- [ ] empty states
- [ ] error states
- [ ] no console errors

## Backend

- [ ] authentication
- [ ] database
- [ ] row-level security
- [ ] authorized sharing
- [ ] delete account/household flow

## SEO

- [ ] unique title/meta per page
- [ ] canonical URLs
- [ ] sitemap
- [ ] robots.txt
- [ ] structured data where appropriate
- [ ] interactive tool available on primary landing pages
- [ ] no thin duplicate keyword pages

## Analytics

- [ ] optimizer_started
- [ ] optimizer_run
- [ ] plan_accepted
- [ ] plan_rebalanced
- [ ] share event
- [ ] account creation event

## Trust

- [ ] privacy policy
- [ ] terms
- [ ] clear data-deletion behavior
- [ ] no misleading fairness claims

## Performance

- [ ] optimized bundle
- [ ] fast initial load
- [ ] optimizer under target runtime

## Launch experiment

Start with a controlled MVP launch and measure:

- visitor → first plan
- first plan → accepted
- accepted → shared
- accepted → returned

Do not optimize for traffic before proving activation.
