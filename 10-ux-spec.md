# 10 — UX Specification

## Product personality

Clear, practical, calm, slightly analytical. Avoid childish chore-chart aesthetics.

## Main journey

### Screen 1 — Start

Headline:

> Stop arguing about who does what.

Supporting text:

> Tell ChoreMatrix how your household works. We'll build the workload plan.

CTA:

**Build my household plan**

No signup.

### Screen 2 — Household

Select preset:

- Couple
- Family
- Roommates
- Multigenerational
- Custom

### Screen 3 — People

Fast cards with capacity presets:

- light
- normal
- high
- custom

### Screen 4 — Work

Use starter task bundles so a user can create a realistic household in minutes.

Starter bundles:

- Basic home
- Family
- Roommates
- Pet household
- Large home

### Screen 5 — Constraints

Progressively reveal advanced options.

### Screen 6 — Generate

Primary CTA:

**Calculate our plan**

### Screen 7 — Results

Top section:

- total work
- total capacity
- overload/shortage
- balance summary

Middle:

- member cards
- weekly board

Bottom:

- exceptions
- explainability
- rebalance

## UX rule

Do not make users configure every possible constraint before they can see a first result.

## Mobile browser

The product must remain functional on mobile browsers, but desktop/tablet is the primary design target for the planning workspace.
