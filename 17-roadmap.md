# 17 — Roadmap

## Phase 0 — Working prototype

- Local browser app
- Household presets
- Member capacity
- Task library
- Constraint handling
- Deterministic optimizer
- Results dashboard
- Rebalance

## Phase 1 — Public MVP

- Production UI
- Responsive design
- SEO landing pages
- local/save workflow
- authentication when saving
- cloud persistence
- sharing
- basic analytics
- legal pages

## Phase 2 — Repeat-use engine

- multi-week rotation
- weekly rollover
- quick "X is unavailable" changes
- task swaps
- saved optimizer presets
- household member invitations

## Phase 3 — Premium

- advanced optimization modes
- multiple saved households
- custom weighting
- history
- exports
- recurring automatic replanning

## Phase 4 — Expansion

Potential expansion into broader household coordination if user behavior supports it:

- errands
- household routines
- pets
- seasonal work
- family responsibilities

Do not expand simply because a feature is possible. Expand only when the core optimizer is used repeatedly.

## Deliberately postponed

- native apps
- chatbots
- AI APIs
- calendar integrations
- push notifications
- gamification
- social network features
