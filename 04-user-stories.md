# 04 — User Stories

## Core generation

- As a household organizer, I want to enter the people in my household so the system knows who can receive work.
- As a household organizer, I want to enter recurring work so the engine knows what must be allocated.
- As a household organizer, I want to set a person's capacity so the plan reflects reality rather than treating everyone equally.
- As a household organizer, I want to exclude people from unsuitable tasks.
- As a household organizer, I want the system to generate a schedule automatically.

## Replanning

- As a user, I want to change one person's availability and regenerate the plan.
- As a user, I want to see which constraints prevented perfect balancing.
- As a user, I want to rebalance without recreating the household.

## Household scenarios

- As a parent, I want to mark age-inappropriate work as unavailable to a child.
- As a roommate, I want recurring shared work to rotate.
- As a couple, I want workload adjusted for different available time.
- As a multigenerational household, I want capacity to matter more than equal task counts.

## Output

- As a user, I want to see each person's total workload.
- As a user, I want to see which tasks each person received.
- As a user, I want to see unassigned work.
- As a user, I want a simple explanation for major assignments.

## Future stories

- Save a household.
- Invite members.
- Share a read-only plan.
- Track completion.
- Regenerate next week automatically.
- Export a printable plan.
